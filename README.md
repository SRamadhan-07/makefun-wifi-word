This program writes exactly one word for the entrant's Wi-Fi — "Gaslighting" — because the connection shows full signal bars while delivering nothing, confidently pretending that everything is fine and the problem must be you. The word is 11 characters long, which sits comfortably inside the competition's 1-to-20 character gate, and the program adds no trailing newline or extra decoration, so the output file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
